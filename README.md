# Tank Cpanel (Android)

1. Create a new GitHub repository and upload ALL files in this folder
   (including the hidden .github folder).
2. Open the repo > Actions > "Build Android APK" (it runs on every push,
   or press "Run workflow").
3. When it turns green, open the run and download the "tank-cpanel-apk"
   artifact. Unzip it to get app-debug.apk.
4. Copy the APK to your phone and install it (allow "install unknown apps").
5. Open the app, allow the Nearby devices permission, and tap
   CONNECT ESP32 (BLUETOOTH).
